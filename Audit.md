# Анализ существующих web-приложений + Git

### 1. Docsity
* **Адрес ресурса:** https://www.docsity.com/ru/
* **Анализ архитектуры и логики:** Платформа представляет собой SPA (Single Page Application). Анализ заголовков (Headers) и исходного кода показывает использование React/Next.js (серверный рендеринг для SEO). Взаимодействие с сервером идет через API: отправка GET/POST запросов и получение ответов в формате JSON без перезагрузки страницы.
* **Семантические элементы HTML5:** Активно используются. Имеется: `<header>`, `<nav>`, `<section>`, `<footer>`.
* **Семантические классы:** Вёрстка модульная, зачастую классы осмысленные (например, `ds-button`, `header-wrapper`, `document-card__title`).
* **Адаптивность ресурса:** Полная адаптивность. Используются Flexbox и media-запросы. На ширине `max-width: 768px` меню сворачивается в "бургер", сетка перестраивается в 1 колонку.
* **Lighthouse Аудит (Условия: Домашний Ethernet, ПК):**
  * Производительность: 92
  * Доступность: 97
  * Best Practices: 73
  * SEO: 66
* **Локальное хранилище и cookies:** В Cookies хранятся данные сессии (`session_id`) и токены безопасности. Local Storage используется очень активно: там хранятся токены гостевой сессии (guestUserToken), идентификаторы сессий и данные систем аналитики.
* **Аналитика и маркетинг:** В Network найдены Google Analytics (`analytics`), Google Tag Manager (`gtm.js`) и Facebook Pixel (`fbevents.js`).

### 2. Студфайл (Studfile)
* **Адрес ресурса:** https://studfile.net/
* **Анализ архитектуры и логики:** Классическая многостраничная архитектура (Server-Side Rendering). Сервер отдает готовый HTML-код. Для подгрузки файлов и работы фильтров используется AJAX.
* **Семантические элементы HTML5:** отсутствуют, в основном используется базовый тег `<div>`.
* **Семантические классы:** Присутствуют осмысленные имена классов с элементами БЭМ-методологии (`docs-list`, `search-form__input`, `btn-download`).
* **Адаптивность ресурса:** Присутствует базовая адаптивность (медиа-запросы перестраивают контент под мобильные устройства).
* **Lighthouse Аудит (Условия: Домашний Ethernet, ПК):**
  * Производительность: 98
  * Доступность: 69 
  * Best Practices: 96
  * SEO: Ошибка проверки (блокировка ботов).
* **Локальное хранилище и cookies:** Local Storage пуст. Основная работа идет через Cookies (хранение `PHPSESSID` для поддержания авторизации).
* **Аналитика и маркетинг:** Загружаются скрипты `analytics.js` (Google), `watch.js` (Yandex.Metrika) и `TagManager`.

### 3. Студворк (Studwork)
* **Адрес ресурса:** https://studwork.ru/
* **Анализ архитектуры и логики:** Монолитное веб-приложение. Формы работают через классический метод POST, фильтрация — через GET. Используется jQuery и частично Vue.js для динамики.
* **Семантические элементы HTML5:** используются `<header>`, `<main>` ,`<nav>`, `<section>`, `<footer>`.
* **Семантические классы:** Читаемые классы, например `task-list-item`, `user-rating`, `btn-primary`.
* **Адаптивность ресурса:** адаптивность через CSS Flexbox.
* **Lighthouse Аудит (Условия: Домашний Ethernet, ПК):**
  * Производительность: 97
  * Доступность: 77
  * Best Practices: 88
  * SEO: 92
* **Локальное хранилище и cookies:** В Local Storage хранятся черновики сообщений в чатах и кэшируются списки ВУЗов. Cookies — для защиты сессии от CSRF-атак.
* **Аналитика и маркетинг:** Yandex.Metrika, Google Analytics, VK Pixel.

### 4. Всё сдал! (vsesdal.com)
* **Адрес ресурса:** https://vsesdal.com/
* **Анализ архитектуры и логики:** Серверная архитектура. Особенность — реализация аукциона в реальном времени. Обновление ленты заказов и чатов идет фоново через AJAX.
* **Семантические элементы HTML5:** верстка на `<nav>`, `<footer>` и дефолтные `<div>`.
* **Семантические классы:** Стандартизированные имена: `form-group`, `header-wrapper`, `order-item`.
* **Адаптивность ресурса:** Адаптирован под мобильные устройства (медиа-запросы меняют параметры `flex-basis` у карточек).
* **Lighthouse Аудит (Условия: Домашний Ethernet, ПК):**
  * Производительность: 96
  * Доступность: 89
  * Best Practices: 96 
  * SEO: 92
* **Локальное хранилище и cookies:** В Local Storage лежит токен авторизации. Cookies стандартные.
* **Аналитика и маркетинг:** Yandex.Metrika, Google Analytics.

## 3. Анализ функциональных возможностей для проекта «УниМаркет»
На основе проведенного аудита выбраны следующие функции для реализации (в порядке приоритета):
1. **Система начисления баллов за загрузку материалов**.  
   *Приоритет:* Критически высокий. Основа экономики платформы.
2. **Безопасная загрузка файлов конспектов**.  
   *Приоритет:* Высокий. Реализация формы с атрибутом `enctype="multipart/form-data"` и методом POST.
3. **Каталог с фильтрацией по предмету и курсу**.  
   *Приоритет:* Высокий. Будет реализован через GET-запросы, чтобы результатами поиска можно было делиться ссылкой.
4. **Биржа срочных заявок с откликами и аукционом цены**.  
   *Приоритет:* Средний.
5. **Система отзывов и рейтинг пользователей.**  
   *Приоритет:* Средний. Необходима для борьбы с некачественными материалами.
