# УниМаркет (UniMarket)

**Учиться легче вместе.** Учебный проект: маркетплейс, где студенты публикуют учебные материалы — конспекты, решённые задачи, шпаргалки — и покупают их друг у друга за внутренние баллы. Реальных денег нет.

Зачем: при регистрации студент получает 100 баллов, автор бесплатного материала — 25 баллов, автор платного — всю цену при продаже (без комиссии), покупатель сразу получает файлы, а 24 часа на проверку и одна замена файла защищают от брака. Единственный актуальный документ требований — [спецификация MVP](docs/mvp/SPECIFICATION.md).

## Что уже работает

- Адаптивный лендинг: Grid на компьютере и планшете, Flexbox на телефоне (требование практической).
- Регистрация в два шага: логин и пароль, затем имя, фамилия, курс и email, которые можно пропустить. После второго шага аккаунт создан и вход выполнен. Повторный вход, сессия и выход. Пароль хранится как Argon2id-хеш.
- PHP подключён к MySQL: 7 таблиц, регистрация создаёт аккаунт и кошелёк со 100 баллами в одной транзакции.
- После входа открывается начальная страница каталога с логином и балансом.
- Автотест доступа и защиты `tests/auth.php`.

Публикация, каталог, покупки и оценки ещё не реализованы.

## Этапы впереди

3. Публикация материала: тип (конспект, решённые задачи, шпаргалка), до 5 файлов, награда за бесплатные материалы.
4. Каталог: поиск, фильтры по типу, предмету, курсу и цене, сортировка по новизне и цене; страница материала.
5. Покупка с резервом баллов и скачивание.
6. Подтверждение покупки и автоподтверждение через 24 часа.
7. Обращение, замена файла, возврат.
8. Оценки продавца (звёзды), избранное, профиль, история баллов.
9. Общая проверка и подготовка к защите.

Чего в MVP нет — раздел [«Не входит в MVP»](docs/mvp/SPECIFICATION.md#3-не-входит-в-mvp) спецификации.

## Локальный запуск

Нужен [Open Server Panel](https://ospanel.io/en/download/) 6 (папка `D:\OSPanel`) с модулями **Apache**, **PHP-8.3** и **MySQL-8.4**. Пошаговая настройка — в [НАСТРОЙКА-ПРОЕКТА.md](НАСТРОЙКА-ПРОЕКТА.md).

1. Запусти панель и включи три модуля.
2. Один раз выполни в корне проекта (PHP из панели: `D:\OSPanel\modules\PHP-8.3\php.exe`):

```powershell
php scripts/init-db.php
```

Скрипт создаёт базу `unimarket`, 7 таблиц, пользователя приложения и локальный `config/local.php`.

3. Открой [http://unimarket.local](http://unimarket.local).

Проект подключён к панели как домен `unimarket.local`: в `D:\OSPanel\home\unimarket.local` лежат `.osp/project.ini` и ссылка `www` (junction) на папку репозитория. Панель не принимает пробелы в путях, поэтому прямой путь `D:\GitHub PROJECTS\unimarket` ей не подходит. Apache отдаёт только `assets`, остальное идёт через `.htaccess` в `router.php`. Docker не нужен.

```powershell
php tests/auth.php
```

Тест проверяет доступ и БД, создаёт и удаляет свой аккаунт; запускать на локальной учебной среде. Пользователей можно посмотреть, сбросить им пароль и удалить в консоли администратора: `php scripts/admin.php`, её проверка — `php tests/admin.php`. Структура и примеры запросов — в [database/README.md](database/README.md).

## Технологии и структура

HTML, обычный CSS и vanilla JavaScript; backend — PHP 8.3 и MySQL 8.4 (модули Open Server Panel). Сборщик, Node.js и фреймворки не нужны. Внешний вид — по файлу Figma «УниМаркет — дизайн» (шрифты Rubik, Onest и Golos Text, цвета в `assets/css/base.css`), адаптация для телефона своя.

```text
index.html        лендинг целиком
pages/            остальные HTML-страницы (вход, каталог)
assets/           CSS, JS, иконки, шрифт
backend/          PHP: сессия, БД, API /api/auth
router.php        белый список страниц и API (за .htaccess)
database/         схема MySQL и её описание
scripts/          подготовка БД
tests/            автотест доступа
docs/             требования, архитектура, прогресс, шпаргалка к защите
```
