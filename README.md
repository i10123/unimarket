# Маркетплейс учебных материалов «УниМаркет» (UniMarket)

Внутривузовская торговая площадка для студентов, предназначенная для обмена учебными материалами (конспектами, шпаргалками, решёнными задачами) и оказания учебных услуг. Проект построен на системе внутренней экономики: вместо реальных денег используются «баллы».

## 📋 Функциональные требования к проекту

**1. Авторизация и профиль пользователя (Студента):**
*   Регистрация и авторизация в системе.
*   Личный кабинет с отображением текущего баланса внутренней валюты («баллов»).
*   История покупок, продаж и загруженных материалов.

**2. Каталог и поиск:**
*   Отображение списка доступных материалов и услуг.
*   Фильтрация материалов по предмету, курсу, типу (шпаргалка, конспект, задача).
*   Поиск по названию.

**3. Экономика и корзина:**
*   Начисление баллов пользователю за загрузку полезных материалов или выполнение заданий.
*   Добавление материалов в корзину и их покупка за внутренние баллы.
*   Списание баллов со счета покупателя и начисление на счет продавца.

**4. Биржа срочных заявок:**
*   Возможность создать заявку (например, «Нужно решить контрольную по матану до завтра»).
*   Система откликов: другие студенты могут предложить свою цену в баллах за выполнение.
*   Выбор исполнителем подходящего отклика и закрытие заявки.

**5. Система рейтинга:**
*   Возможность оставить отзыв и оценку (рейтинг) продавцу/исполнителю после завершения сделки или покупки материала.

## 💻 Технологический стек

Проект разрабатывается без использования тяжелых frontend-фреймворков (без React/Vue/Angular), с упором на классическую веб-разработку.

*   **Frontend:**
    *   HTML5 (разметка)
    *   CSS3 (стилизация, возможен отказ от препроцессоров или использование Bootstrap по договоренности)
    *   Vanilla JavaScript (чистый JS для интерактивности, работы с DOM, корзиной и AJAX-запросами).
*   **Backend:**
    *   PHP (обработка бизнес-логики, маршрутизация, работа с сессиями и базой данных).
*   **База данных:**
    *   MySQL / MariaDB (хранение информации о пользователях, товарах, заявках, транзакциях баллов).
*   **Среда разработки / Сервер:**
    *   XAMPP / OpenServer / MAMP (для локального развертывания).
