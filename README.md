# УниМаркет (UniMarket)

Учебный проект: маркетплейс, где студенты публикуют конспекты, решённые задачи и шпаргалки и покупают их друг у друга за внутренние баллы. Реальных денег нет.

Баллы работают так. За регистрацию студент получает 100 баллов, за бесплатный материал автор получает 25, а за платный получает его цену при продаже, без комиссии. Покупатель сразу получает файлы. Если с файлом что-то не так, он пишет продавцу: контакты есть у каждого пользователя и видны всем. Требования собраны в одном документе, [спецификации MVP](docs/mvp/SPECIFICATION.md).

## Что работает

- Адаптивный лендинг. На компьютере и планшете он построен на Grid, на телефоне на Flexbox, как требует практическая.
- Регистрация в три шага. Сначала логин и пароль, потом имя, фамилия, курс и email (этот шаг можно пропустить), потом обязательные контакты для связи: свободный текст от 5 символов. После регистрации начисляется 100 баллов. Вход и регистрация лежат на отдельных страницах, пароль хранится как хеш Argon2id.
- Публикация материала с типом, предметом, курсом и ценой. К материалу можно приложить до 10 файлов по 15 МБ любого формата, в том числе архивы. Бесплатный материал приносит автору 25 баллов. В день можно опубликовать не больше 5 материалов. Свой материал можно потом отредактировать (поля, цену и файлы, каждый файл убирается крестиком) или снять с публикации.
- Каталог с поиском, фильтрами по предмету, курсу, типу и цене, шестью сортировками (новые, старые, дешевле, дороже, больше и меньше оценок) и кнопкой «Показать ещё». Купленные материалы из общего каталога пропадают. Есть страница материала, избранное и профиль автора.
- Покупка: баллы сразу переходят продавцу, файлы открываются сразу, скачать их могут только автор и покупатель. Контакты продавца видны на странице материала, в профиле автора и в «Мои покупки». После покупки можно оценить продавца.
- Кабинет с балансом, историей баллов, покупками, своими материалами, настройками профиля и сменой пароля.

Почты и восстановления пароля нет. Страница «Восстановить доступ» честно сообщает, что функция пока не готова. Всё остальное, чего в MVP нет, перечислено в разделе [«Не входит в MVP»](docs/mvp/SPECIFICATION.md#3-не-входит-в-mvp) спецификации.

## Локальный запуск

Нужен [Open Server Panel](https://ospanel.io/en/download/) 6 (папка `D:\OSPanel`) с модулями Apache, PHP-8.3 и MySQL-8.4. Пошаговая настройка описана в [НАСТРОЙКА-ПРОЕКТА.md](НАСТРОЙКА-ПРОЕКТА.md).

1. Запусти панель и включи три модуля.
2. Один раз выполни в корне проекта (PHP из панели: `D:\OSPanel\modules\PHP-8.3\php.exe`):

```powershell
php scripts/init-db.php
```

Скрипт создаст базу `unimarket`, 7 таблиц, пользователя приложения и локальный файл `config/local.php`.

3. Для показа заполни базу тестовыми данными: 10 демо-пользователей `demo01` … `demo10` и 50 их материалов, у каждого по одному файлу `.md`. Пароль лежит в константе `DEMO_PASSWORD` в `scripts/seed.php`. Скрипт можно запускать повторно, он обновляет только демо-данные:

```powershell
php scripts/seed.php
```

4. Открой [http://unimarket.local](http://unimarket.local).

Проект подключён к панели как домен `unimarket.local`. В `D:\OSPanel\home\unimarket.local` лежат `.osp/project.ini` и ссылка `www` (junction) на папку репозитория. Панель не принимает пробелы в путях, поэтому прямой путь `D:\GitHub PROJECTS\unimarket` ей не подходит. Apache отдаёт только `assets`, остальное идёт через `.htaccess` в `router.php`. Docker не нужен.

Консоль администратора запускается командой `php scripts/admin.php`: она показывает пользователей, статистику каждого, сбрасывает пароль и удаляет. Команда `php scripts/seed.php demo` создаёт те же демо-данные и добавляет покупки с оценками, а `php scripts/seed.php clear` удаляет демо-данные. После обновления проекта выполни `php scripts/init-db.php`: скрипт сам переведёт базу старой схемы на новую (подробности в [database/README.md](database/README.md)).

## Технологии и структура

Проект написан на HTML, обычном CSS и vanilla JavaScript. Backend работает на PHP 8.3 и MySQL 8.4 из модулей Open Server Panel. Сборщик, Node.js и фреймворки не нужны. Внешний вид взят из файла Figma «УниМаркет: дизайн» (шрифты Rubik, Onest и Golos Text, цвета в `assets/css/base.css`), мобильную версию мы адаптировали сами.

```text
index.html        лендинг целиком
pages/            остальные HTML-страницы (вход, регистрация, каталог, кабинет)
assets/           CSS, JS, иконки, шрифт
backend/          PHP: сессия, БД, классы Market и Deals, API в backend/api/
router.php        белый список страниц и API (за .htaccess)
database/         схема MySQL и её описание
scripts/          подготовка БД, тестовые данные, консоль администратора
docs/             требования, архитектура, шпаргалка к защите
```
