# УниМаркет (UniMarket)

**Учиться легче вместе.** Учебный проект студенческой платформы, где можно делиться конспектами и другими материалами, находить консультации и получать помощь по своим задачам. Расчёты внутри приложения ведутся в баллах.

Текущая учебная версия — магазин материалов с расчётами в баллах. Услуги, заявки, чаты и админка исключены. Оценки продавца — только звёзды без текста после завершения покупки. Актуальные правила определяет [спецификация](docs/SPECIFICATION.md); старые макеты показывают более широкий охват.

## Статус

Работают адаптивный лендинг, регистрация по email/паролю с немедленным входом, повторный вход, сессия и выход. PHP подключён к локальной MySQL: созданы 7 таблиц, регистрация создаёт аккаунт и нулевой кошелёк в транзакции. После входа открывается начальный каталог с email и балансом. Публикация, покупки и оценки ещё не реализованы.

Восстановление, повтор пароля, имя, фамилия и курс убраны из регистрации. Email остаётся логином, письма не отправляются. Пароль хранится как Argon2id-хеш.

## Локальный запуск

Требуется PowerShell 7. Проверь версию в терминале:

```powershell
$PSVersionTable.PSVersion
```

В результате должна быть версия `7.x`. Запусти PowerShell 7 командой `pwsh`, перейди в папку проекта и выполни:

```powershell
pwsh
.\scripts\start.ps1
```

Если команда `pwsh` не найдена, PowerShell 7 не установлен. Windows PowerShell 5.1 запускается через `powershell`, а PowerShell 7 — через `pwsh`; это разные программы. Скрипты сохранены в UTF-8 и рассчитаны на запуск из PowerShell 7.

Открыть [http://127.0.0.1:8000](http://127.0.0.1:8000). Скрипт использует установленный PHP с pdo_mysql и при первом запуске загружает MySQL Community Server 8.4.13 LTS из официального архива с проверкой опубликованной контрольной суммы. Docker и служба Windows не требуются. БД слушает только 127.0.0.1:3306, данные сохраняются в storage/mysql8; реквизиты — в игнорируемом config/local.php. PHP-сервер предназначен для локальной разработки.

```powershell
php tests/auth.php
.\scripts\stop.ps1
```

Первая команда проверяет доступ и БД, вторая штатно останавливает локальные серверы. Тест создаёт и удаляет свой аккаунт; запускать на локальной учебной среде. Структура и примеры запросов — в [database/README.md](database/README.md).

Ниже описан целевой функционал по файлу Figma «УниМаркет — дизайн», проверенному через Figwright 22 октября 2026. Наличие экрана в дизайне не означает, что возможность уже реализована.

Лендинг предназначен для гостей. Карточки на нём демонстрационные: названия материалов без ссылок, сердца и каталог ведут на вход без ID материала. PHP перенаправляет вошедшего пользователя в начальный каталог, гостя с закрытой страницы — на вход.

## Возможности по макетам

Последнее решение пользователя ограничивает реализацию материалами: услуги, заявки и отклики из исходных макетов пока исключены. Публикации поддерживают до пяти файлов, включая ZIP, и автоматическое одобрение. Отзывы, избранное, профиль, поиск и фильтры сохраняются; способ связи с продавцом и подтверждение покупки уточняются. Таблица ниже описывает исходный более широкий дизайн, а актуальный объём — [спецификация](docs/SPECIFICATION.md).

| Раздел | Назначение |
|---|---|
| Лендинг | Знакомство с платформой, примеры материалов, получение баллов и FAQ |
| Аккаунт | Регистрация по email и паролю с автоматическим входом, последующий вход и выход. Письма, подтверждение адреса и восстановление исключены из учебной версии |
| Материалы | Поиск, фильтры по предмету, курсу, типу и цене; сортировка; описание и покупка |
| Услуги | Консультации, разбор задач и другие предложения; фильтры по формату, длительности и цене |
| Заявки студентов | Создание и редактирование задачи с бюджетом и сроком; отклики; выбор исполнителя заказчиком |
| Общение и заказы | Чат, согласование условий, оплата баллами, подтверждение выполнения и отзыв |
| Избранное и авторы | Сохранённые материалы, профиль автора, рейтинг и отзывы |
| Личный кабинет | Баланс, мои материалы, публикации и их статусы, история покупок и баллов, настройки |
| Публикация | Размещение материала или услуги; отправка материала на проверку |
| Модерация | Список материалов на проверке, просмотр файла, публикация или отклонение |
| Помощь | Правила, ответы на вопросы и обращение по проблеме |

Материал покупается непосредственно на его странице. **Корзина в проекте не предусмотрена.** После покупки доступ к файлу должен появляться в личном кабинете.

Для услуги сначала согласуются детали в чате. По описанию в разделе помощи баллы резервируются и передаются исполнителю после принятия результата; серверную реализацию этого сценария ещё предстоит разработать.

Правила уточнены пользователем 29 октября: за каждый впервые одобренный материал автор получает 100 баллов независимо от продаж; при покупке вся цена передаётся автору без комиссии. Бесплатные материалы разрешены. Подробные правила и открытые вопросы — в [спецификации](docs/SPECIFICATION.md); суммы прочих примеров в макетах остаются демонстрационными.

## Дизайн и адаптивность

В Figma есть страницы «00 · Стиль и компоненты», «01 · Desktop», «02 · Mobile» и «админка». Используем актуальные компоненты; карточка с пометкой Legacy остаётся прежней версией.

- Основная гарнитура — Manrope; цвета и параметры приведены в [справочнике дизайна](docs/learning/02-design-reference.md).
- Требование практической: основная раскладка главной на компьютере и планшете — Grid; на телефоне — Flexbox через media-запросы.
- Карточки: от 1200 px — четыре колонки Grid, 768–1199 px — две колонки Grid, 600–767 px — два столбца Flexbox, до 600 px — колонка Flexbox. Вход и регистрация видны обычными кнопками от 600px; ниже — двумя ссылками с иконками, без выпадающего меню. Адаптация разработана самостоятельно, без повторения мобильных макетов Figma.
- При защите нужно объяснять и менять число колонок, промежутки, направление и выравнивание элементов.

## Технологии и структура

Frontend — HTML, обычный CSS и JavaScript без React/Vue/Angular. Backend — PHP 8.5 и MySQL Community Server 8.4.13 LTS. Сборщик и Node.js для приложения не требуются.

Целевое расположение файлов:

```text
index.html      — лендинг целиком
pages/          — остальные самостоятельные HTML-страницы
assets/css/     — общие стили и оформление страниц
assets/js/      — поведение страниц и общие функции
assets/icons/   — иконки из Figma
assets/fonts/   — файлы шрифтов
docs/           — архитектура и рабочие заметки
```

Структура создаётся по мере работы. Для регистрации и входа запускать PHP через scripts/start.ps1: открытие HTML напрямую и Live Server не выполняют backend. Лицензия шрифта — assets/fonts/OFL-Manrope.txt. Подробности — в [ARCHITECTURE.md](docs/ARCHITECTURE.md).

Код поддерживаем кратким и читаемым: KISS, DRY, одна ответственность на файл. Жёсткого ограничения числа строк нет; 300–400 строк HTML для одной страницы допустимы. ООП применяем к логике, где оно полезно. Правила сотрудничества и обязательный навык ponytail зафиксированы в [AGENTS.md](AGENTS.md).
