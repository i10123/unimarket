# УниМаркет (UniMarket)

**Учиться легче вместе.** Учебный проект студенческой платформы, где можно делиться конспектами и другими материалами, находить консультации и получать помощь по своим задачам. Расчёты внутри приложения ведутся в баллах.

Каталог объединяет три направления: **материалы**, **услуги** и **заявки студентов**. Пользователь может приобрести готовый материал, договориться о консультации или создать заявку, на которую откликнутся другие студенты. Баллы предусмотрены за публикацию одобренных материалов и выполнение заказов.

## Статус

Созданы адаптивный лендинг в index.html и единая страница входа, регистрации и восстановления в pages/auth/login.html. Стили — assets/css, локальный Manrope — assets/fonts, SVG — assets/icons. FAQ работает средствами HTML; auth.js показывает пароль и проверяет поля, без отправки данных. Серверная часть ещё не реализована. Документация находится в docs. Страницы работают без сборки.

Ниже описан целевой функционал по файлу Figma «УниМаркет — дизайн», проверенному через Figwright 22 октября 2026. Наличие экрана в дизайне не означает, что возможность уже реализована.

Лендинг предназначен для гостей. Карточки на нём демонстрационные: названия материалов без ссылок, сердца и каталог ведут на вход без ID материала. После авторизации предусмотрен настоящий каталог; проверка сессии и перенаправление ещё не реализованы.

| Услуги | Консультации, разбор задач и другие предложения; фильтры по формату, длительности и цене |
| Заявки студентов | Создание и редактирование задачи с бюджетом и сроком; отклики; выбор исполнителя заказчиком |
| Общение и заказы | Чат, согласование условий, оплата баллами, подтверждение выполнения и отзыв |
| Избранное и авторы | Сохранённые материалы, профиль автора, рейтинг и отзывы |
| Личный кабинет | Баланс, мои материалы, публикации и их статусы, история покупок и баллов, настройки |
| Публикация | Размещение материала или услуги; отправка материала на проверку |
| Модерация | Список материалов на проверке, просмотр файла, публикация или отклонение |
| Помощь | Правила, ответы на вопросы и обращение по проблеме |

Материал покупается непосредственно на его странице. **Корзина в проекте не предусмотрена.** После покупки доступ к файлу должен появляться в личном кабинете.

Для услуги сначала согласуются детали в чате. По описанию в разделе помощи баллы резервируются и передаются исполнителю после принятия результата; серверную реализацию этого сценария ещё предстоит разработать.

Точный размер награды за одобрение материала пока не закреплён: в макетах встречаются разные примеры. Суммы, балансы и количество карточек в дизайне — демонстрационные данные.

## Дизайн и адаптивность

В Figma есть страницы «00 · Стиль и компоненты», «01 · Desktop», «02 · Mobile» и «админка». Используем актуальные компоненты; карточка с пометкой Legacy остаётся прежней версией.

- Основная гарнитура — Manrope; цвета и параметры приведены в [справочнике дизайна](docs/learning/02-design-reference.md).
- Требование практической: основная раскладка главной на компьютере и планшете — Grid; на телефоне — Flexbox через media-запросы.
- Карточки: от 1200 px — четыре колонки Grid, 768–1199 px — две колонки Grid, 600–767 px — два столбца Flexbox, до 600 px — колонка Flexbox. Вход и регистрация видны обычными кнопками от 600px; ниже — двумя ссылками с иконками, без выпадающего меню. Адаптация разработана самостоятельно, без повторения мобильных макетов Figma.
- При защите нужно объяснять и менять число колонок, промежутки, направление и выравнивание элементов.

## Технологии и структура

Frontend — HTML, обычный CSS и JavaScript без React/Vue/Angular. Планируемый backend — PHP, база — MySQL/MariaDB. Для HTML/CSS сборщик и Node.js не требуются.

Целевое расположение файлов:

```text
index.html      — лендинг целиком
pages/          — остальные самостоятельные HTML-страницы
assets/css/     — общие стили и оформление страниц
assets/js/      — поведение страниц и общие функции
assets/icons/   — иконки из Figma
assets/fonts/   — файлы шрифтов
docs/           — архитектура и рабочие заметки
```

Структура создаётся по мере работы. Сейчас есть [index.html](index.html), [страница доступа](pages/auth/login.html) и assets/css, assets/js, assets/fonts, assets/icons; остальные разделы ещё не созданы. HTML можно открыть напрямую в браузере. Во время разработки также подходит локальный HTTP-сервер, например Live Server. Лицензия шрифта — assets/fonts/OFL-Manrope.txt. Подробности — в [ARCHITECTURE.md](docs/ARCHITECTURE.md).

Код поддерживаем кратким и читаемым: KISS, DRY, одна ответственность на файл. Жёсткого ограничения числа строк нет; 300–400 строк HTML для одной страницы допустимы. ООП применяем к логике, где оно полезно. Правила сотрудничества и обязательный навык ponytail зафиксированы в [AGENTS.md](AGENTS.md).
