# УниМаркет: настройка компьютера

Проект работает на Windows x64 и Open Server Panel 6. Docker, WSL и Node.js не нужны. Обновлено 9 ноября 2026.

## 1. Что нужно

| Компонент | Версия и источник |
|---|---|
| Open Server Panel | Версия 6.x с [ospanel.io/en/download](https://ospanel.io/en/download/). Бесплатная загрузка медленная, файл весит около 1,7 ГБ. Ставить в `D:\OSPanel`: в пути не должно быть пробелов и кириллицы |
| Модули панели | Apache 2.4, PHP-8.3 (с `pdo_mysql`) и MySQL-8.4. Не самую новую версию PHP выбрали по совету преподавателя |
| Git и браузер | Чтобы получить исходники и проверить сайт |

## 2. Порядок

1. Запусти панель и включи модули. Это можно сделать в меню панели или в её консоли (`cmd`, не PowerShell): `osp on PHP-8.3`, `osp on MySQL-8.4`, `osp on Apache`.
2. Создай файл `D:\OSPanel\home\unimarket.local\.osp\project.ini`. Скопируй `home\example.local\.osp\project.ini` и укажи в нём `[unimarket.local]`, `http_engine = Apache`, `php_engine = PHP-8.3`, `project_root = {base_dir}\www`, `web_root = {base_dir}\www`.
3. Создай ссылку на репозиторий. Панель не принимает пробелы в пути, поэтому прямой путь `D:\GitHub PROJECTS\unimarket` не подойдёт:

```powershell
New-Item -ItemType Junction -Path 'D:\OSPanel\home\unimarket.local\www' -Target '<путь к репозиторию>'
```

4. Перезапусти панель: выполни `osp exit` в cmd и запусти `D:\OSPanel\bin\ospanel.exe`. Проект подхватывается при старте. В выводе `osp projects` должна появиться строка `unimarket.local  Apache  8.3  Включён`, а в логе `D:\OSPanel\logs\general.log` не должно быть ошибок домена.
5. Подготовь базу из корня проекта: `D:\OSPanel\modules\PHP-8.3\php.exe scripts/init-db.php`. Скрипт создаст базу `unimarket`, 7 таблиц, пользователя `unimarket` и файл `config/local.php`. Его нельзя публиковать.
6. Для показа заполни базу тестовыми данными: `D:\OSPanel\modules\PHP-8.3\php.exe scripts/seed.php`. Если демо-данные уже есть, команда ничего не меняет. Пересоздать их можно командой `scripts/seed.php fresh`, но покупки живых аккаунтов у демо-материалов при этом пропадут. Если схема базы менялась, сначала снова выполни шаг 5: `init-db.php` сам переведёт старую базу на новую схему.
7. Открой `http://unimarket.local`.
8. Чтобы смотреть базу в браузере, переименуй папку `D:\OSPanel\home\phpmyadmin` в `phpmyadmin.local`, укажи в её `.osp\project.ini` `[phpmyadmin.local]`, `http_engine = Apache`, `php_engine = PHP-8.3`, перезапусти панель и открой `http://phpmyadmin.local`.

## 3. Проверка

- Закрытые пути должны отвечать 403 или 404: `/config/local.php`, `/backend/api/auth.php`, `/database/schema.sql`, `/storage/sessions`.
- В браузере лендинг открывается без ошибок в Console. Дальше пройди путь: регистрация, каталог, публикация и покупка, выход, вход.

## 4. Типичные проблемы

| Симптом | Что проверить |
|---|---|
| Страница «Как вы здесь оказались?» | Проект не подхвачен. Посмотри `osp projects` и `logs\general.log`, перезапусти панель |
| В логе «Недопустимые символы в пути» | В `project.ini` указан путь с пробелом. Используй ссылку `www` |
| Открываются `backend/` или `config/` | Не работает `.htaccess`. Проверь, включены ли `mod_rewrite` и `AllowOverride All` |
| `could not find driver` или нет подключения к БД | Включён ли MySQL-8.4 и есть ли `mysql-8.4.local` в hosts (панель прописывает его при запуске) |
| Домен не открывается | Панель должна работать: файл hosts меняется только при её запуске |
| Порт 80 или 3306 занят | Останови чужие Apache, IIS или MySQL. Команда `osp status` покажет состояние панели |
