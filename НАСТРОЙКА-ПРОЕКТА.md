# УниМаркет: настройка компьютера

Среда — Windows x64 и Open Server Panel 6; Docker, WSL и Node.js не нужны. Обновлено 9 ноября 2026.

## 1. Что нужно

| Компонент | Версия и источник |
|---|---|
| Open Server Panel | 6.x с [ospanel.io/en/download](https://ospanel.io/en/download/); бесплатная загрузка медленная (около 1,7 ГБ). Ставить в `D:\OSPanel`: путь без пробелов и кириллицы |
| Модули панели | Apache 2.4, PHP-8.3 (с `pdo_mysql`), MySQL-8.4. Выбрана не самая новая версия PHP по совету преподавателя |
| Git и браузер | Для получения исходников и проверки |

## 2. Порядок

1. Запустить панель и включить модули. В консоли панели (`cmd`, не PowerShell): `osp on PHP-8.3`, `osp on MySQL-8.4`, `osp on Apache`; либо в меню панели.
2. Создать папку проекта `D:\OSPanel\home\unimarket.local\.osp\project.ini`: скопировать `home\example.local\.osp\project.ini` и указать `[unimarket.local]`, `http_engine = Apache`, `php_engine = PHP-8.3`, `project_root = {base_dir}\www`, `web_root = {base_dir}\www`.
3. Создать ссылку на репозиторий (панель не принимает пробелы в пути, поэтому прямой путь `D:\GitHub PROJECTS\unimarket` не работает):

```powershell
New-Item -ItemType Junction -Path 'D:\OSPanel\home\unimarket.local\www' -Target '<путь к репозиторию>'
```

4. Перезапустить панель (`osp exit` в cmd и запустить `D:\OSPanel\bin\ospanel.exe`): проект подхватывается при старте. В `osp projects` должна быть строка `unimarket.local  Apache  8.3  Включён`; в логе `D:\OSPanel\logs\general.log` ошибок домена быть не должно.
5. Подготовить БД из корня проекта: `D:\OSPanel\modules\PHP-8.3\php.exe scripts/init-db.php`. Скрипт создаёт базу `unimarket`, 7 таблиц, пользователя `unimarket` и `config/local.php` (не публиковать).
6. Для показа заполнить БД тестовыми данными: `D:\OSPanel\modules\PHP-8.3\php.exe scripts/seed.php` (повторный запуск обновляет только демо-данные). Если схема БД менялась, сначала удалить базу `unimarket` в phpMyAdmin и повторить шаг 5.
7. Открыть `http://unimarket.local`.
8. Для просмотра БД: папку `D:\OSPanel\home\phpmyadmin` переименовать в `phpmyadmin.local`, в её `.osp\project.ini` указать `[phpmyadmin.local]`, `http_engine = Apache`, `php_engine = PHP-8.3`, перезапустить панель и открыть `http://phpmyadmin.local`.

## 3. Проверка

- Закрытые пути отдают 403/404: `/config/local.php`, `/backend/api/auth.php`, `/database/schema.sql`, `/storage/sessions`.
- В браузере: лендинг без ошибок в Console, регистрация → каталог → публикация и покупка → выход → вход.

## 4. Типичные проблемы

| Симптом | Что проверить |
|---|---|
| Страница «Как вы здесь оказались?» | Проект не подхвачен: `osp projects`, `logs\general.log`, перезапуск панели |
| «Недопустимые символы в пути» в логе | В `project.ini` путь с пробелом; использовать ссылку `www` |
| Открываются `backend/` или `config/` | Не работает `.htaccess`: включён ли `mod_rewrite` и `AllowOverride All` |
| `could not find driver` или нет подключения к БД | Включён ли MySQL-8.4; есть ли `mysql-8.4.local` в hosts (панель прописывает при запуске) |
| Домен не открывается | Панель должна работать; hosts меняется только при запуске панели |
| Порт 80 или 3306 занят | Остановить чужие Apache/IIS/MySQL; в панели команда `osp status` |
