# Рабочая БД «УниМаркет»

MySQL 8.4 (модуль Open Server Panel), InnoDB, UTF-8. [schema.sql](schema.sql) применён локально; всего 7 таблиц. Все таблицы используются приложением. Все внешние ключи с ON DELETE CASCADE: удаление пользователя в консоли администратора убирает его кошелёк, материалы, покупки и историю. Данные сервера хранит панель в D:\OSPanel\data.

| Таблица | Основные данные и ключи | Связи |
|---|---|---|
| users | PK id, уникальный логин, хеш пароля, необязательные имя, фамилия, email и курс | Аккаунт покупателя и продавца один |
| wallets | PK/FK user_id, доступный остаток и резерв | Пользователь 1:1 кошелёк |
| materials | PK id, FK author_id, название, описание, предмет, обязательный тип (`notes` — конспект, `solutions` — решённые задачи, `cheatsheet` — шпаргалка), курс, цена, состояние | Автор 1:N материалы |
| purchases | PK id, FK buyer_id/material_id, цена при покупке, состояние и срок, проблема, факт замены, оценка 1–5 | Покупатель и материал 1:N покупки; покупка связывает пользователей и материалы M:N |
| files | PK id, FK material_id **либо** purchase_id, закрытое имя хранения, исходное имя, формат и размер | Исходные файлы 1:N к материалу; замена 1:N к покупке |
| favorites | Составной PK/FK user_id + material_id | Пользователи M:N материалы |
| point_entries | PK id, FK user_id, ссылка на покупку либо награждённый материал (у бонуса при регистрации ссылок нет), вид и изменение остатков | Кошелёк 1:N записи истории |

Одна оценка хранится в каждой завершённой покупке, но показывается как оценка продавца. Текста отзыва нет; отдельная таблица оценок не нужна. Смена автора уже опубликованного/купленного материала не предусматривается.

У одного покупателя одна запись приобретения конкретного материала; повторное приобретение после возврата не предусмотрено. Ограничение «до пяти исходных файлов», запрет покупки своего материала, сроки, однократная замена и согласованное движение баллов проверяет PHP (классы Market и Deals) в транзакциях: одни внешние ключи этого не обеспечивают.

При регистрации начисляются 100 баллов, в `point_entries` появляется запись вида `welcome` без ссылки на покупку и материал. За каждый бесплатный материал автор получает 25 баллов (вид `reward`); таблица истории допускает одну такую запись на материал. За платный материал награды нет.

## Понятные запросы

Знаки `?` — параметры PHP PDO, а не подстановка текста в SQL.

```sql
-- Данные аккаунта и остатки: поиск по первичному ключу.
SELECT u.id, u.login, w.available, w.reserved
FROM users u JOIN wallets w ON w.user_id = u.id
WHERE u.id = ?;

-- Последние опубликованные материалы: индекс catalog.
SELECT id, author_id, title, price
FROM materials
WHERE status = 'published'
ORDER BY created_at DESC, id DESC
LIMIT 20;

-- Каталог с фильтром по типу, сначала дешёвые: индекс filters отбирает строки, сортирует MySQL отдельно.
SELECT id, title, subject, course, price
FROM materials
WHERE status = 'published' AND type = ?
ORDER BY price ASC, id DESC
LIMIT 20;

-- Покупки конкретного пользователя: индекс начинается с buyer_id.
SELECT p.id, m.title, p.price, p.status, p.purchased_at
FROM purchases p JOIN materials m ON m.id = p.material_id
WHERE p.buyer_id = ?
ORDER BY p.purchased_at DESC
LIMIT 20;

-- Среднее число звёзд и количество оценок аккаунта продавца.
SELECT ROUND(AVG(p.rating), 1) AS rating, COUNT(p.rating) AS ratings_count
FROM materials m JOIN purchases p ON p.material_id = m.id
WHERE m.author_id = ? AND p.status = 'completed';

-- Сохранить звёзды: проверяются владелец покупки и её завершение.
UPDATE purchases SET rating = ?
WHERE id = ? AND buyer_id = ? AND status = 'completed' AND rating IS NULL;

-- Добавление в избранное; повторная пара отклоняется уникальным ключом.
INSERT INTO favorites (user_id, material_id) VALUES (?, ?);

-- Удаление только своего сохранения.
DELETE FROM favorites WHERE user_id = ? AND material_id = ?;
```

Уникальный логин ускоряет вход и не допускает дубликаты. Индексы обслуживают каталог: catalog — сортировку по новизне, filters (status, type, subject, course, price) — фильтры по типу, предмету, курсу и цене; deadlines — будущую обработку истёкших сроков; history — историю кошелька. Скорость под нагрузкой не измерялась, полнотекстовый поиск пока не реализован.

## Локальное подключение

- Адрес БД: `mysql-8.4.local` (127.0.1.31 в hosts, прописывает панель), порт `3306`, база `unimarket`, пользователь `unimarket`.
- Пароль приложения находится в локальном `config/local.php`; не публиковать его. Этот пользователь имеет только SELECT/INSERT/UPDATE/DELETE, не меняет структуру БД.
- Сервер БД — модуль MySQL-8.4 Open Server Panel; перед работой включить его в панели.
- `scripts/init-db.php` подключается как `root` без пароля (настройка панели по умолчанию, MySQL слушает только локальный адрес). Повторный запуск создаёт недостающие таблицы, но не является системой миграций и не изменяет уже существующие поля.
- Просмотр в браузере: [http://phpmyadmin.local](http://phpmyadmin.local) (phpMyAdmin из Open Server Panel). В списке «Текущий сервер» выбрать `MySQL-8.4 (root)`, затем база `unimarket`; после регистрации на сайте обновить таблицу `users`. Проект панели `D:\OSPanel\home\phpmyadmin.local` переименован из `phpmyadmin` и использует Apache и PHP-8.3.
