# Текущий формат работы

Обновлено 22 октября 2026. Работаем небольшими шагами: готовый фрагмент, точное место вставки, короткое объяснение, проверка результата. По просьбе пользователя ИИ сам создаёт или изменяет файлы. Предварительное заучивание синтаксиса не требуется.

Чтобы восстановить контекст, читать по порядку:

1. [PROFILE.md](PROFILE.md) — цель, предпочтения и ограничения.
2. [PROGRESS.md](PROGRESS.md) — выполненное, оставшееся и ближайший предлагаемый шаг.
3. [PROJECT_MAP.md](PROJECT_MAP.md) — реальные файлы, матрица разделов, ответственность, связи и открытые решения.

Затем проверить реальные исходники: пользователь мог изменить их после последнего обновления записей. Состояние и чек-лист ведутся в PROGRESS, а не дублируются здесь.

Параметры Figma и шпаргалки остаются справочниками. Старый подробный практикум не является обязательным порядком обучения. VibeWise изучен, но не установлен и не активирован.
