## Требование преподавателя

> Выполнить вёрстку главной страницы приложения в виде Grid для больших экранов (компьютер, планшет) и сделать адаптивность для телефонных экранов с помощью media-запросов, с использованием FlexBox. При защите практической уметь на ходу вносить изменения и преобразования в CSS, владеть базовыми принципами построения FlexBox и Grid.

Для нашего упражнения: главный контейнер и сетка материалов на компьютере и планшете используют Grid. На телефоне эти же контейнеры через media-запрос становятся Flexbox. Вложенные строки и содержимое карточек могут использовать Flexbox при любой ширине.

Первая учебная страница — гостевой лендинг «Учиться легче вместе». Каталог — отдельная основная страница приложения, которую собираем позже тем же способом Grid → Flexbox. Это позволяет показать требуемую раскладку и на лендинге, и на каталоге, если при защите преподаватель подразумевает под главной именно каталог.

Десктоп и ПК-версия — одно и то же. Рабочий цикл: сначала десктоп, затем планшет, затем телефон, затем проверка промежуточных ширин. У каждой страницы один HTML-документ, адаптация выполняется CSS.

## Как будем проверять твою работу

Присылай текущие файлы или просто напиши, что они появились в этом репозитории, и укажи законченные шаги. Полезно добавить: «ожидал вот это, получил вот это, пробовал изменить вот это».

Проверка: что получилось, где проблема и как исправить. Могу дать готовую замену нужного фрагмента с местом вставки, а по твоей просьбе сам внести исправления в файлы. Не требую самостоятельно найти синтаксис или решить архитектурную задачу перед продолжением.

Завершённый этап — это не только похожий внешний вид: нужно уметь объяснить свой HTML, показать Grid и Flexbox в DevTools и самостоятельно изменить несколько правил. В конце первого задания есть отдельная репетиция защиты.
