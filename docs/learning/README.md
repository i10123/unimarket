## Требование преподавателя

> Выполнить вёрстку главной страницы приложения в виде Grid для больших экранов (компьютер, планшет) и сделать адаптивность для телефонных экранов с помощью media-запросов, с использованием FlexBox. При защите практической уметь на ходу вносить изменения и преобразования в CSS, владеть базовыми принципами построения FlexBox и Grid.

У нас: главный контейнер и сетка материалов лендинга на ПК и планшете — Grid; на телефоне те же контейнеры через media-запрос становятся Flexbox. Каталог позже собирается тем же способом, если преподаватель под «главной» имеет в виду каталог. На защите нужно уметь показать Grid и Flexbox в DevTools и на ходу изменить несколько правил — см. «Разбор для защиты» в PROGRESS.md.
