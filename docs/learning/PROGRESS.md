## Разбор для защиты

В landing.css правило `.material-grid` задаёт `repeat(4, minmax(0, 1fr))`: четыре равные колонки. `1fr` делит свободную ширину, `minmax(0, ...)` позволяет колонкам сжиматься, а `gap` задаёт промежутки. Внутри карточки `flex: 1` у содержимого занимает свободную высоту и прижимает цену с автором к низу.

На 1199 px и уже media-запрос меняет число колонок на две. На телефоне до 768px позднее правило переключает контейнер в Flexbox; старое grid-template-columns остаётся в CSS, но для Flexbox не действует. До 600px направление column, на 600–767px flex-flow: row wrap и flex: 1 1 calc(50% - 8px) располагают карточки по две с учётом gap: 16px. min-height: 0 убирает прежний минимум 228px: содержимое сохраняется, лишняя пустая высота исчезает. Абсолютное положение сердца сохраняет область нажатия 44px без увеличения строки метаданных.

Мини-практика: на десктопе временно заменить четыре колонки на три; изменить gap с 16 на 24 px; вернуть исходные значения. Затем на телефоне найти правило `flex-direction: column` и объяснить, почему карточки идут сверху вниз. Это упражнение пока не выполнено пользователем.

Для защиты: до 600px display: none скрывает текст ссылок, а display: block показывает их иконки. max-width: none снимает ограничение 280px у кнопки приветствия. Мини-практика: временно поменять порог на 560px и посмотреть, когда появляются текстовые кнопки; затем вернуть 600px.

Проверены 390, 599, 600, 743 и 768px: переполнения нет. Для защиты: row меняет направление, space-between распределяет свободное место между элементами.
