## Связи

```text
login.html + auth.js ──fetch──▶ router.php ──▶ backend/auth.php ──▶ AuthHandler ──▶ MySQL
catalog.html + account.js ──GET /api/auth──▶ currentUser() ──▶ users JOIN wallets
```

Данные: пользователь 1:1 кошелёк, 1:N материалы; покупки связывают покупателей и материалы (M:N); файлы принадлежат материалу либо покупке (замена); история баллов — записи кошелька.

## Разделы MVP и дизайн

Файл Figma: «УниМаркет — дизайн», Desktop `2:147`, компоненты `0:1`, лендинг `38:2404`, вход `3:3809`, регистрация `3:3855`. Мобильные макеты не используются — адаптация своя. Перед новыми экранами проверить Figwright.

| Раздел | Статус |
|---|---|
| Лендинг, вход и регистрация | Готово |
| Публикация, каталог, страница материала | Макеты найдены, код не начат |
| Покупки, продажи, замена | Код не начат |
| Избранное, профиль, настройки | Макеты найдены, код не начат |
| Услуги, заявки, чаты, админка | Есть в старом макете, исключены — не восстанавливать |
