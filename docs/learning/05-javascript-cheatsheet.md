# JavaScript: база и подсказки для поведения

На первой странице JavaScript понадобится для меню и, при желании, локальной демонстрации избранного. Расположение элементов выполняет CSS. Переходы по обычным ссылкам и FAQ через details могут работать без собственного JS.

## Как читать задачу

Для каждого поведения сначала назови четыре вещи: **событие → данные → изменение состояния → обновление интерфейса**. Например: нажали сердце → узнали ID материала → поменяли признак сохранения → изменили вид и доступное название кнопки.

Если не можешь описать действие словами, пока рано писать обработчик.

## База языка

| Инструмент | Что означает | Пример применения без готового решения |
|---|---|---|
| `const` | Переменная, которой не присваивают другое значение | Найденная кнопка или ID материала |
| `let` | Переменная с возможным новым присваиванием | Текущее открытое состояние |
| Строка | Текст в кавычках | Название, CSS-селектор, ключ хранилища |
| Число | Числовое значение | Цена 120, число карточек |
| `true`, `false` | Логические значения | Меню открыто или закрыто |
| `null` | Явное отсутствие значения | Поиск элемента ничего не нашёл |
| `undefined` | Значение ещё не определено / отсутствует | Нет свойства объекта |
| Массив | Упорядоченный набор | Список ID сохранённых материалов |
| Объект | Именованные свойства | Материал: ID, название, цена |
| Функция | Повторяемое действие с параметрами и результатом | Обновить вид одного элемента |
| `return` | Возврат результата и выход из функции | Вернуть найденный материал |
| `if`, `else` | Выбор по условию | Открыть или закрыть меню |
| `===`, `!==` | Строгое сравнение | Совпадает ли ID |
| `&&`, `||`, `!` | И, или, отрицание | Элемент найден и действие разрешено |
| `for...of` | Последовательный обход значений | Обработать несколько кнопок |
| `forEach()` | Вызвать действие для каждого элемента | Назначить обработчики нескольким кнопкам |
| `includes()` | Проверить наличие в массиве | Уже сохранён ли ID |
| `filter()` | Получить новый массив по условию | Удалить один ID из списка |
| `map()` | Получить новый массив преобразованных значений | Позже: подготовить список свойств материалов |

`=` присваивает значение, `===` сравнивает. Строка «120» и число 120 — разные типы; для расчётов требуется осознанное преобразование. `const` запрещает новое присваивание переменной, но не делает массив или объект неизменяемым.

## DOM: найти, прочитать, изменить

| API | Что делает | На что обратить внимание |
|---|---|---|
| `document.querySelector()` | Первый элемент по CSS-селектору | Может вернуть null |
| `document.querySelectorAll()` | Набор совпадений | Не один элемент; нужен обход |
| `element.textContent` | Прочитать или заменить обычный текст | Подходит для текста от пользователя |
| `element.classList.add/remove/toggle` | Изменить классы состояния | Внешний вид пусть задаёт CSS |
| `element.getAttribute/setAttribute` | Читать и менять атрибуты | Например, aria-expanded |
| `element.hidden` | Скрыть или показать элемент | Правила display в CSS не должны случайно отменять скрытое состояние |
| `element.dataset` | Читать data-атрибуты | data-material-id доступен как dataset.materialId; значение — строка |
| `element.closest()` | Найти себя или ближайшего подходящего предка | Полезно, когда нажат вложенный значок |
| `document.createElement()` | Создать DOM-элемент | Пригодится в динамическом каталоге позже |
| `append()` | Добавить созданный элемент | Само создание ещё не показывает его на странице |
| `remove()` | Удалить элемент из DOM | Позже: удалить карточку из избранного |

Не вставляй пользовательские строки через `innerHTML`: браузер воспринимает их как HTML. Для обычных названий и сообщений используй textContent. Полная генерация карточек JavaScript на первом занятии не нужна — сначала удобно видеть их структуру в HTML.

## События

| Инструмент | Для чего |
|---|---|
| `addEventListener()` | Связать событие с обработчиком |
| `click` | Активация кнопки или ссылки |
| `input` | Изменение ввода по мере набора |
| `change` | Подтверждённое изменение значения, например выбора |
| `submit` | Отправка формы, в том числе клавишей Enter |
| `keydown` | Нажатие клавиши, например Escape |
| `event.target` | Элемент, на котором возникло событие; может быть вложенной иконкой |
| `event.currentTarget` | Элемент, чей обработчик сейчас выполняется |
| `preventDefault()` | Отменить стандартное действие, например настоящую отправку учебной формы |

События могут всплывать от ребёнка к родителю. Поэтому кнопка внутри кликабельной области требует аккуратной структуры. Для лендинга проще иметь независимую ссылку на материал и независимую кнопку избранного.

Обычные button активируются клавиатурой без ручного дублирования Enter и Space. Для ссылок не нужно перехватывать click ради обычного перехода.

## Упражнение 1: мобильное меню

Подготовь в HTML кнопку меню и область навигации. Свяжи их уникальным ID и атрибутом `aria-controls`; начальное `aria-expanded` должно соответствовать закрытому состоянию.

Алгоритм словами:

1. Найди кнопку и панель. Если их нет на данной странице, не запускай её обработчики.
2. При активации кнопки определи следующее состояние.
3. Измени видимость панели и значение aria-expanded согласованно.
4. При Escape закрой панель и верни фокус на кнопку открытия.
5. Проверь, что скрытые ссылки не получают Tab-фокус.
6. После перехода к большой ширине страницы проверь состояние: мобильная панель не должна ломать десктопную навигацию.

Для первого занятия достаточно раскрывающейся немодальной панели в потоке страницы. Полноэкранный диалог с блокировкой фона и управлением фокусом — отдельная, более сложная задача. Такой упрощённый вид панели является учебным решением; её точный дизайн не извлечён из проверенного фрейма лендинга.

Подсказки: querySelector, addEventListener, hidden, setAttribute, keydown, focus. Не добавляй прямые вычисления ширины карточек в JavaScript.

## Упражнение 2: избранное — после CSS

Для статической практической достаточно правильно показать начальные состояния из макета. Если хочешь отработать JS, сделай переключение сердца в текущей странице.

1. Дай каждому материалу устойчивый ID. Текст названия не должен быть идентификатором.
2. Найди все кнопки сохранения.
3. Свяжи нажатие с состоянием конкретного материала.
4. Меняй CSS-класс, aria-pressed и доступное название согласованно.
5. Проверь, что нажатие сердца не открывает страницу материала.

Это локальное учебное поведение. В итоговом приложении решение о доступности избранного для гостя и хранение пользовательского списка нужно связать с аккаунтом.

## Сохранение после перезагрузки — необязательное продолжение

| API | Назначение |
|---|---|
| `localStorage.getItem()` | Прочитать строку по ключу; отсутствующий ключ возвращает null |
| `localStorage.setItem()` | Сохранить строку |
| `JSON.stringify()` | Превратить данные в JSON-строку |
| `JSON.parse()` | Прочитать данные из JSON-строки; некорректная строка вызывает ошибку |
| `try...catch` | Обработать ошибку, например повреждённые сохранённые данные |

Храни список ID, а не копию всей HTML-карточки. При загрузке проверь тип прочитанных данных. Для стабильной проверки используй локальный HTTP-сервер; поведение localStorage для страниц, открытых напрямую как file, не стоит считать основой приложения.

LocalStorage не является базой аккаунтов. Пароли, подтверждение оплаты, право скачать файл и настоящий баланс через него не реализуются.

## Что JavaScript не обязан делать на первом занятии

- Переключать Grid на Flexbox — это media-запрос CSS.
- Открывать обычную ссылку вручную.
- Заменять встроенное поведение details без дополнительной задачи.
- Запрашивать сервер, если на этом этапе нет API.
- Генерировать всю страницу из данных.

Позже пригодятся `fetch`, `async` / `await`, обработка ответа сервера и сетевых ошибок. Изучать их удобнее на каталоге или форме с реальным API, а не для изменения отступов.

## Как искать ошибку

1. Открой Console и прочитай первое сообщение об ошибке, включая имя файла и строку.
2. Если написано о null — проверь селектор и момент выполнения скрипта.
3. Если реакция отсутствует — проверь загрузку JS в Network, назначение обработчика и правильный элемент.
4. Временно используй `console.log()` для события и текущего состояния.
5. Если одна кнопка работает, а другие нет — проверь, не использован ли querySelector вместо querySelectorAll.
6. После исправления перезагрузи страницу и повтори действие с клавиатуры.

Держи одну переменную или модель источником состояния; не позволяй классу, aria-атрибуту и localStorage независимо говорить о трёх разных состояниях одной кнопки.
