# CSS: инструменты для «УниМаркета»

CSS-правило состоит из селектора и набора свойств. Селектор определяет, к кому применяется правило; свойство и значение определяют изменение. Ниже отдельные названия и значения для самостоятельного составления правил, без готовой таблицы стилей страницы.

## Где искать причину, если правило не работает

| Проверка | Что посмотреть |
|---|---|
| Файл загрузился? | Network, путь в link, отсутствие 404 |
| Селектор совпал? | Имя класса в HTML и CSS, точка у класса в селекторе |
| Правило активно? | Нужная ширина окна и условие media-запроса |
| Его перебили? | Зачёркнутые свойства во вкладке Styles, итог во вкладке Computed |
| Правило на том элементе? | Layout-свойства контейнера и свойства его детей различаются |
| Не мешают размеры? | Фиксированная ширина, min-width, padding, длинное слово |

Класс выбирается через `.имя`, ID — через `#имя`, тег — его названием. Селектор с пробелом ищет потомка, с `>` — непосредственного ребёнка. `:hover` описывает наведение, `:focus-visible` — видимый фокус, `[open]` — наличие атрибута open.

При обычных авторских правилах ID специфичнее класса, класс специфичнее тега. Порядок правил решает при одинаковой специфичности и прочих равных. Не исправляй каждую проблему добавлением `!important`: сначала найди конфликт в DevTools.

## Размеры и отступы

| Свойство | Для чего | Где пригодится |
|---|---|---|
| `box-sizing: border-box` | Включает padding и границу в заданные размеры | Базовое правило для всех элементов, включая псевдоэлементы |
| `margin` | Внешний отступ элемента | Промежуток снаружи, центрирование контейнера |
| `padding` | Внутренний отступ до содержимого | 32 в приветствии, 16 в карточке |
| `gap` | Промежуток между детьми Grid/Flexbox | 16 между карточками |
| `width` / `inline-size` | Ширина | Заполнение доступного пространства |
| `max-width` / `max-inline-size` | Ограничение сверху | Контейнер до 1280 px |
| `min-width` / `min-inline-size` | Ограничение снизу | Значение 0 помогает детям Flex/Grid сжиматься |
| `min-height` | Минимальная высота с возможностью роста | Карточка при длинном названии |
| `height` | Жёсткая высота | Иконка; для текстовых блоков применять осторожно |
| `overflow-wrap` | Перенос длинной неразрывной строки | Необычно длинное название или адрес |
| `overflow` | Что делать с содержимым за границей | Не скрывать переполнение всей страницы ради маскировки ошибки |

Четыре значения padding/margin идут по часовой стрелке: верх → право → низ → лево. Два значения: вертикаль → горизонталь. Логические свойства `padding-inline` и `margin-inline` задают горизонтальные стороны при обычном русском направлении письма.

`margin-inline: auto` центрирует блок ограниченной ширины. `gap` действует на детей контейнера и не добавляет внешние поля. У заголовков и абзацев есть браузерные margin: сбрось или задай их осознанно, иначе отступы сложатся неожиданно.

## Единицы и функции

| Инструмент | Смысл |
|---|---|
| `px` | CSS-пиксель; удобен для сравнения с макетом |
| `%` | Доля размера соответствующего содержащего блока; база зависит от свойства |
| `rem` | Относительно корневого размера шрифта; обычно 1rem = 16px, пока настройки не изменены |
| `em` | Относительно размера шрифта в данном контексте |
| `fr` | Доля свободного места в Grid после учёта других размеров и промежутков |
| `auto` | Размер или распределение, определяемое правилами раскладки |
| `min()` / `max()` | Выбор меньшего / большего из значений |
| `minmax()` | Минимум и максимум размера трека Grid |
| `repeat()` | Повторение колонок или строк |
| `calc()` | Вычисление с совместимыми единицами |
| `clamp()` | Значение между нижней и верхней границей |

Ширина 100% плюс внешний margin может дать переполнение. `100vw` может учитывать ширину полосы прокрутки; обычному контентному контейнеру чаще нужна доступная ширина родителя.

## Типографика и внешний вид

| Свойство | Применение |
|---|---|
| `font-family` | Manrope и запасная системная гарнитура |
| `font-size` | Размер текста |
| `font-weight` | 400 / 500 / 600 / 700 / 800 |
| `line-height` | Межстрочный; 1.4 означает 140% текущего размера текста |
| `color` | Цвет текста и элементов, использующих currentColor |
| `background-color` | Фон блока |
| `border` | Толщина, вид и цвет границы |
| `border-radius` | Скругление |
| `text-decoration` | Оформление ссылки; не убирай все признаки интерактивности |
| `text-align` | Выравнивание текста внутри блока |
| `outline`, `outline-offset` | Видимый фокус без изменения размера элемента |
| `transition` | Короткое плавное изменение, например цвета; не обязательна для первой версии |

`@font-face` описывает локальный файл шрифта. Проверяй кириллицу и наличие нужных насыщенностей. Если используешь переменный шрифт, диапазон веса должен быть объявлен подходящим образом; не называй обычный статический файл переменным.

## CSS-переменные

Общие значения удобно объявить в `:root`. Имя начинается с `--`, применение — через `var(имя)`. Например, `--color-accent` обозначает основной цвет действия; `--space-16` — повторяемый размер отступа.

В HTML класс выбирает назначение компонента, а CSS-переменная хранит значение. Один общий класс карточки плюс модификатор голубого или сиреневого фона удобнее четырёх полностью независимых правил карточек.

## Grid — контейнер

Grid распределяет элементы по колонкам и строкам. Трек — одна колонка или строка; линия — её граница. Непосредственные дети grid-контейнера становятся grid-элементами.

| Свойство | Что меняет | Практика |
|---|---|---|
| `display: grid` | Включает Grid | Главный поток и список карточек на десктопе/планшете |
| `grid-template-columns` | Количество и размеры колонок | Значение `repeat(4, minmax(0, 1fr))` — четыре равные колонки |
| `grid-template-rows` | Явные строки | Обычно текстовые секции могут расти автоматически |
| `gap`, `column-gap`, `row-gap` | Промежутки | Можно менять межстрочный и межколоночный отдельно |
| `grid-template-areas` | Именованные области | Удобно для каркаса шапка / содержимое / подвал |
| `align-items` | Выравнивание детей внутри их областей по блочной оси | Выровнять высоту карточек в строке |
| `justify-items` | Выравнивание детей внутри областей по строчной оси | Растянуть или выровнять отдельные блоки |
| `align-content`, `justify-content` | Распределение всей сетки в свободном месте контейнера | Видно, когда сетка меньше контейнера |

Для равных колонок `minmax(0, 1fr)` позволяет колонке сжиматься ниже автоматического минимума содержимого. Это не заменяет перенос длинных слов внутри элемента.

## Grid — ребёнок

| Свойство | Что меняет |
|---|---|
| `grid-column` | От каких до каких линий занимает место ребёнок; `1 / -1` — вся явная сетка |
| `grid-row` | Размещение по строкам |
| `grid-area` | Назначение именованной области |
| `align-self`, `justify-self` | Выравнивание только одного ребёнка |

Не задавай четыре колонки самому article ради размещения четырёх article. Четыре колонки нужны их родителю. Grid влияет на непосредственных детей; заголовок внутри карточки не становится элементом внешней сетки.

## Flexbox — контейнер

Flexbox распределяет элементы вдоль главной оси. Поперечная ось перпендикулярна главной. При `row` главная ось горизонтальная, при `column` — вертикальная в обычном направлении письма.

| Свойство | Что меняет | Применение |
|---|---|---|
| `display: flex` | Включает Flexbox | Ряды в карточке, кнопки, мобильная колонка |
| `flex-direction` | Главную ось: `row` / `column` | Телефонный список — column |
| `flex-wrap` | Разрешение переноса на новые линии | Группа кнопок, если не помещается |
| `gap` | Промежутки между детьми | 8, 12, 16, 20, 24 по контексту |
| `justify-content` | Распределение по главной оси | `space-between` — автор и цена по краям |
| `align-items` | Выравнивание по поперечной оси | `center` — элементы строки по центру высоты |
| `align-content` | Распределение нескольких flex-линий при наличии свободного места | Не выравнивает обычную одиночную строку |

При смене row на column смысл justify-content тоже поворачивается. Если колонка не имеет лишней высоты, распределять свободное вертикальное место нечему.

## Flexbox — ребёнок

| Свойство | Что меняет | Применение |
|---|---|---|
| `flex-grow` | Получение свободного места | Средняя область карточки занимает остаток высоты |
| `flex-shrink` | Участие в сжатии | Иконка обычно не должна сжиматься |
| `flex-basis` | Исходный размер по главной оси | Основа для расчёта размера ребёнка |
| `flex` | Краткая запись grow / shrink / basis | Понимай составляющие перед использованием |
| `align-self` | Поперечное выравнивание одного ребёнка | Отдельная кнопка |
| `order` | Визуальный порядок | Не меняет порядок DOM и обычно клавиатуры; не строить на нём смысловой порядок |
| Автоматический margin | Поглощение свободного места на стороне | `margin-top: auto` может прижать нижнюю строку в колонке |

`flex: 1` и `width: 100%` не равнозначны. Первое участвует в распределении места Flexbox; второе задаёт ширину. При column свойство flex-basis относится к высоте, а не ширине.

## Grid или Flexbox в нашем задании

| Участок | Десктоп и планшет | Телефон |
|---|---|---|
| Основной поток main | Grid, одна колонка разделов | Flexbox, column |
| Список материалов | Grid: 4, затем 2 колонки | Flexbox: column |
| Приветственный блок | Grid: две области, на тесном планшете допустима одна | Flexbox: column |
| Внутри карточки | Flexbox: column + строки | Flexbox: column + строки |
| Блок создания заявки | Grid: текст и действие | Flexbox: column |
| Подвал | Grid для бренда и центральных ссылок | Flexbox: column |

Одна колонка тоже может быть Grid. Главное доказательство владения Grid здесь — реальная сетка материалов и распределение областей, а не только наличие слова grid в CSS.

## Медиазапросы: desktop-first

1. Сначала опиши большие экраны обычными правилами.
2. Затем в `@media` для ширины до 1199 px переопредели только нужные отличия планшета: колонки, поля, ширины групп. Сохрани Grid.
3. Ниже запиши телефонное условие `max-width: 767px`: переключи нужные контейнеры на `display: flex`, задай `flex-direction: column`, пересмотри ширины и поля.
4. Проверь пересечение условий: на 390 px действуют и базовые, и планшетные, и телефонные правила. При равной специфичности позднее телефонное правило должно переопределять нужные свойства.
5. Смена display не сбрасывает старый width, min-height, margin или flex-свойства. Проверь, что жёсткие десктопные размеры не пережили переключение.

Breakpoint — ширина переключения правил, viewport — доступная область страницы. Границы 1200 и 768 — предложенный учебный старт, не измеренные точки из Figma. Проверяй соседние значения 1199/1200 и 767/768.

Для адаптации не нужны второй HTML-файл, проверка модели телефона в JS или уменьшение всей страницы через transform.

## Как читать Figma и переносить в CSS

| Figma | Возможный инструмент CSS |
|---|---|
| Auto Layout horizontal / vertical | Flexbox row / column или Grid по назначению блока |
| Gap | gap |
| Padding | padding |
| Fill container | Получение доступного места: растяжение, flex-grow или доля Grid |
| Hug contents | Размер по содержимому; не фиксировать высоту текста |
| Space between | justify-content: space-between в Flexbox |
| Radius | border-radius |
| Color variable | CSS-переменная по смыслу |
| Координаты x/y | Положение в редакторе; не готовые margin, left и top |

## Отладка перед вопросом наставнику

Выдели неправильный элемент в Elements. Посмотри box model: ширину, padding, border и margin. Включи Grid/Flex overlay у родителя. Временно отключай подозрительные свойства по одному, чтобы увидеть причину. После удачного опыта перенеси изменение из DevTools в файл: правка только в браузере обычно пропадёт после перезагрузки.

Если появился горизонтальный скролл, найди выступающий элемент: фиксированная ширина, несжимающийся ребёнок, длинная строка, сумма полей. `overflow-x: hidden` на body скрывает симптом, но может спрятать содержимое и фокус.
