# MVP «УниМаркет»

Дата: 6 ноября 2026. Единственный актуальный документ требований. Полный первоначальный замысел (услуги, заявки, чаты, админка, старые модели БД) лежит в [../full](../full/README.md) и задачей не является. Спецификация определяет поведение, Figma — внешний вид.

**Суть:** студенты публикуют учебные материалы и покупают их за внутренние баллы. Стек: HTML, CSS, vanilla JS, PHP, MySQL 8.4. БД — 7 таблиц в [database/schema.sql](../../database/schema.sql).

## 1. Что входит в MVP

| Раздел | Поведение | Статус |
|---|---|---|
| Аккаунт | Регистрация по логину и паролю → сразу вход; повторный вход; выход. Логин: 3–32 символа (латиница, цифры, _ . -), без учёта регистра, показывается как имя продавца. Создаётся кошелёк с нулём баллов | Готово |
| Публикация | Название, описание, предмет, курс, цена ≥ 0, до 5 файлов (ZIP и др.). После технической проверки файлов материал публикуется сразу. Автор получает +100 баллов один раз за каждый материал | Не начато |
| Каталог | Только опубликованные материалы; поиск, фильтры по предмету, курсу и цене; загрузка порциями | Заглушка |
| Страница материала | Описание, автор, цена, кнопка покупки. Корзины нет | Не начато |
| Покупка | См. раздел 2 | Не начато |
| Мои покупки / продажи | Скачивание купленных файлов, подтверждение, обращение, замена или возврат | Не начато |
| Оценка продавца | 1–5 звёзд без текста после завершения покупки; в профиле — средняя и число оценок | Не начато |
| Избранное | Добавить/убрать материал, свой список без дублей | Не начато |
| Профиль и настройки | Данные по Figma, история баллов, смена пароля (старый → новый) | Не начато |

## 2. Правила покупки

1. Нельзя купить свой материал; один материал покупается пользователем один раз. Повторный запрос не списывает баллы снова.
2. Цена 0 разрешена: доступ выдаётся без движения баллов.
3. При оплате баллы уходят из доступного остатка в резерв, файлы открываются сразу.
4. Резерв переходит продавцу целиком (без комиссии), когда покупатель нажал «Подтвердить» или прошло 24 часа после оплаты без обращения.
5. **Одно обращение:** в первые 24 часа покупатель жмёт «Проблема с файлом» и описывает её. Автоподтверждение останавливается.
6. **Одна замена:** у продавца 24 часа, чтобы загрузить исправленный файл к этой покупке или вернуть резерв. Успешная замена сразу завершает покупку и передаёт резерв продавцу. Ничего не сделал — резерв возвращается покупателю. Опоздавшая или сломанная загрузка выплату не вызывает.
7. Завершённая покупка (подтверждение, автоподтверждение, замена) открывает оценку; возврат — нет. Возврат уже выплаченных баллов не предусмотрен.

## 3. Не входит в MVP

Услуги, заявки, отклики, чат и сообщения, админка и модерация, апелляции, повторные замены, email, письма и восстановление пароля (забытый пароль не восстановить), корзина, реальные деньги, комиссии, текстовые отзывы, версии файлов.

## 4. Качество

- Права, суммы и сроки проверяет PHP; скрытая кнопка не защита.
- Покупка, резерв, выплата, возврат и награда — одна транзакция; каждое изменение баланса пишется в `point_entries`.
- Пароли — хеши; SQL — только с параметрами; пользовательский текст выводится безопасно.
- Закрытые файлы не отдаются статикой: скачать может только автор или покупатель.
- Клавиатура, видимый фокус, понятные ошибки и пустые состояния. Главная: Grid на ПК/планшете, Flexbox на телефоне.

## 5. Порядок работы

1. ✅ Среда, MySQL, схема.
2. ✅ Регистрация, вход, выход.
3. Публикация материала с файлами и наградой.
4. Каталог, поиск, фильтры, страница материала.
5. Покупка с резервом и скачивание.
6. Подтверждение и автоподтверждение через 24 часа.
7. Обращение, замена, возврат.
8. Оценки, избранное, профиль, история баллов.
9. Общая проверка и подготовка к защите.

## 6. Критерии приёмки

| Сценарий | Результат |
|---|---|
| Аккаунт | Регистрация сразу входит; повторный логин, неверный пароль и чужой доступ отклоняются |
| Публикация | Материал с ≤ 5 файлами появляется в каталоге; награда начислена один раз |
| Покупка | Другой пользователь покупает и скачивает; повтор не списывает дважды; остатки совпадают с историей |
| Закрытый файл | Без права файл не скачивается даже по прямому адресу |
| Подтверждение | Подтверждение или 24 часа без обращения передают резерв продавцу ровно один раз |
| Замена / возврат | Обращение останавливает выплату; замена в срок платит продавцу, просрочка возвращает резерв покупателю — ровно один раз |

## 7. Открытые вопросы

- Награда +100: автоматически за каждую публикацию или после отдельной проверки права?
- Точный список форматов и лимит размера файлов — решить до этапа 3.
- Видит ли гость настоящий каталог (сейчас — только после входа).
- Как обрабатывать истёкшие 24 часа без планировщика — решить на этапе 6.
