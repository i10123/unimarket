# Замысел полной версии «УниМаркета»

Перенесено из README при выделении ветки `mvp` (9 ноября 2026). Здесь описан расширенный замысел по макетам Figma «УниМаркет — дизайн» (проверен через Figwright 22 октября 2026). Это **не требования**: актуальное поведение MVP задаёт [../mvp/SPECIFICATION.md](../mvp/SPECIFICATION.md). Наличие экрана в макете не означает, что возможность реализована.

Что из замысла уже вошло в MVP, видно в колонке «В MVP»; всё остальное — идеи для развития, к которым возвращаемся после MVP.

## Возможности по макетам

| Раздел | Замысел | В MVP |
|---|---|---|
| Лендинг | Знакомство с платформой, примеры материалов, получение баллов, FAQ | Да, готов |
| Аккаунт | Регистрация, вход, выход. Первоначально — с email и восстановлением пароля | Да, но только логин и пароль; email и восстановление исключены |
| Материалы | Поиск, фильтры по предмету, курсу, типу и цене, сортировка, описание и покупка | Да (этап 4) |
| Услуги | Консультации, разбор задач и другие предложения; фильтры по формату, длительности и цене | Нет |
| Заявки студентов | Создание и редактирование задачи с бюджетом и сроком, отклики, выбор исполнителя заказчиком | Нет |
| Общение и заказы | Чат, согласование условий, оплата баллами, подтверждение выполнения и отзыв | Нет (в MVP — покупка материала с резервом баллов и подтверждением) |
| Избранное и авторы | Сохранённые материалы, профиль автора, рейтинг и отзывы | Избранное и оценка звёздами; текстовых отзывов нет |
| Личный кабинет | Баланс, мои материалы и их статусы, история покупок и баллов, настройки | Частично: покупки, продажи, история баллов, смена пароля |
| Публикация | Размещение материала или услуги; отправка материала на проверку | Только материал, без проверки модератором: после технической проверки файлов публикуется сразу |
| Модерация | Список материалов на проверке, просмотр файла, публикация или отклонение | Нет |
| Помощь | Правила, ответы на вопросы, обращение по проблеме | FAQ на лендинге; обращение по проблеме с файлом — в покупке |

Материал покупается на его странице. **Корзины нет.** Для услуги в замысле сначала согласуются детали в чате, затем баллы резервируются и передаются исполнителю после принятия результата; серверная реализация этого сценария не разрабатывалась.

Правила баллов, уточнённые 29 октября: за каждый впервые одобренный материал автор получает 100 баллов независимо от продаж; при покупке вся цена передаётся автору без комиссии; бесплатные материалы разрешены.

## Дизайн и адаптивность

В Figma есть страницы «00 · Стиль и компоненты», «01 · Desktop», «02 · Mobile» и «админка». Используются актуальные компоненты; карточка с пометкой Legacy остаётся прежней версией. Мобильные макеты в MVP не используются: адаптация разработана независимо.

- Основная гарнитура — Manrope; цвета заданы переменными в `assets/css/base.css`.
- Требование практической: основная раскладка главной на компьютере и планшете — Grid; на телефоне — Flexbox через media-запросы.
- Карточки: от 1200 px — четыре колонки Grid, 768–1199 px — две колонки Grid, 600–767 px — два столбца Flexbox, до 600 px — колонка Flexbox. Вход и регистрация видны обычными кнопками от 600 px; ниже — двумя ссылками с иконками.
- При защите нужно уметь объяснять и менять число колонок, промежутки, направление и выравнивание элементов.
